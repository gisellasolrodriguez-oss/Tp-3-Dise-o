Se uso la propiedad CSS position y el apilamiento visual con z-index. Para la creación del tooltip, se asignó position: relative al elemento padre con el fin de establecerlo como referencia espacial. Dentro de este contenedor, el texto emergente se ubicó utilizando position: absolute y un z-index: 10 para garantizar su correcto centrado y superposición sobre otros elementos. Por otro lado, el botón flotante "Volver Arriba" se construyó utilizando un enlace ancla que aprovecha el desplazamiento suave nativo de HTML sin requerir JavaScript. Finalmente, este botón se ancló en la esquina inferior derecha de la pantalla mediante position: fixed y un z-index: 50 para asegurar su visibilidad ininterrumpida durante el scroll del usuario.
