El uso de variables globales en :root permite centralizar los tokens de diseño como colores, espaciados y bordes para que estén disponibles en todo el documento. Esta estrategia facilita enormemente la creación de distintos temas visuales mediante la simple reasignación de valores a través de clases específicas como .modo-oscuro. Como resultado, los elementos que implementan la función var() se repintan automáticamente al detectar estos cambios, evitando la duplicación innecesaria de reglas CSS. Adicionalmente, el sistema de diseño se potencia al combinar estas variables con la función calc() para realizar operaciones matemáticas en tiempo real. Esto garantiza que los márgenes y rellenos mantengan siempre proporciones exactas y escalables a partir de un único número base.
