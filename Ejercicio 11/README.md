Se aplicaron Pseudo-clase :nth-child(odd) o :nth-child(even) para lograr el efecto de filas alternas (o "cebreado"). Los elementos de la lista tienen fondos de color diferente intercalados (uno celeste claro, uno blanco).

Pseudo-elemento ::before: utilizado para insertar el pequeño triángulo verde (▹) antes del texto de cada elemento de la lista, usando la propiedad CSS content.

También los enlaces tienen aplicada la pseudo-clase :hover para cambiar de estilo.
