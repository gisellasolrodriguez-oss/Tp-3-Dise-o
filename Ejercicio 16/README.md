Implementación de animaciones fluidas utilizando la regla @keyframes y la propiedad animation. Para la aparición de las tarjetas se diseñó un efecto visual que anima las propiedades opacity y transform, garantizando así un rendimiento óptimo en el navegador. Esta entrada utiliza una función de tiempo ease-out para lograr un movimiento natural, combinándose con retrasos escalonados (animation-delay) para crear una presentación en cascada. Por otro lado, se construyó un indicador de carga circular (spinner) a partir de bordes CSS que gira ininterrumpidamente gracias a la propiedad infinite. A este spinner se le aplicó estrictamente la función de tiempo linear para asegurar una velocidad de rotación constante y evitar tirones visuales.
