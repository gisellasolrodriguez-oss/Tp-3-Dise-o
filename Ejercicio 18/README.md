La galería logra un diseño responsivo sin necesidad de Media Queries gracias a grid-template-columns: repeat(auto-fill, minmax(...)), que calcula automáticamente la cantidad de columnas según el espacio disponible. Para lograr el efecto de mosaico continuo, la propiedad grid-auto-flow: dense instruye al navegador a rellenar los huecos vacíos reordenando inteligentemente los elementos más pequeños. Además, se utilizaron modificadores como span 2 en filas y columnas para romper la simetría y cumplir con el requisito de crear tarjetas de diferentes proporciones. Finalmente, el uso de la propiedad object-fit: cover garantiza que todas las fotografías llenen sus respectivos contenedores asimétricos sin estirarse ni deformarse visualmente.
